# IC Design Repository — Antigravity Engineering Rules

- Work from the written specification; separate requirements, assumptions, RTL and evidence.
- Answer technical questions in Vietnamese while preserving English signal/EDA terminology.
- Do not claim a design is correct from an AI review alone. Show real test outputs.
- No automatic dependency installation, file deletion, credential access, git push, or edits outside the workspace.
- Before modifying an existing file: describe the plan and ask approval; preserve uncommitted work.
- Never commit secrets, API keys, `.env` files, raw credentials or personal data.
- For Phase 2 example and command references, see `labs/phase2_counter/README.md`.
